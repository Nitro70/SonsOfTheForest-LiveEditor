IMPORTANT - 'SPAWNABLE' MEANS TWO DIFFERENT THINGS

  Every one of the 308 items below has a world pickup prefab, so ALL of them can be
  placed in the world by mod tooling that calls UnityEngine Instantiate directly.
  VERIFIED: all 308 were spawned this way in a single sweep, 0 failures.

  The  spawnitem  console command is stricter - it obeys each item's internal
  canBeSpawned flag, and 60 items have that flag set to false. That is the only
  difference between the two lists below.

  Worked example: the 8 artifact items (707, 662, 667, 668, 669, 689, 708, 712) all
  have canBeSpawned=false, so  spawnitem  refuses them - yet all 8 were spawned
  successfully by mod tooling and confirmed on screen by their lightning effect.

  Vehicles are a separate system again: the golf cart is NOT an item and does not
  appear anywhere in this list. Use  addprefab golfcart.

OPENING THE CONSOLE
  With RedLoader installed : cheats are enabled automatically. Press F1.
  Vanilla game             : type  cheatstick  while in-world (nothing appears to
                             happen), then press F1.
  Multiplayer              : the host controls cheats via Options > Gameplay >
                             Allow Cheats. Clients follow the host's setting.

ARGUMENT COLUMN
  string  - takes a value or a toggle, e.g.  godmode on
  none    - takes no argument, just run it

====================================================================================================
HOW THIS DIFFERS FROM THE COMMONLY-CIRCULATED LISTS
====================================================================================================
  - Item count is 308, not 352. The widely-copied lists carry debug/unrealized
    ids that do not exist in this build.
  - Item names here are the game's own display names. Several commonly-listed names
    are wrong: id 78 is 'Log' (internal Log_Legacy), id 355 is 'Pistol' not
    'Compact Pistol', id 431 is 'Firefighter Axe' not 'Fire Axe'.
  - Stack ceilings are included (ammo caps at 1000, logs at 2). Most lists omit them.
  - 418 commands are listed, against the usual ~314. Lists built by scanning for
    _<name> methods miss every command registered at runtime - including addcharacter.
  - 16 of the listed commands come from RedLoader and DO NOT EXIST in the vanilla game.
    They are tagged [RedLoader-only].
  - Unverified descriptions and filler text are omitted rather than repeated.
